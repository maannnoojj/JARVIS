# JARVIS — AI Meeting Buddy

**JARVIS** is a smart assistant app that automates scheduling, prepares agendas, sends reminders, and captures follow-ups. It transforms messy vendor–distributor meetings into organized, productive, and trust-building conversations.

## ✨ Features

- **Automated Scheduling** — Coordinates and books meeting times without back-and-forth emails.
- **Agenda Preparation** — Generates structured agendas ahead of each meeting.
- **Smart Reminders** — Sends timely notifications to all participants.
- **Follow-up Capture** — Records action items and decisions so nothing falls through the cracks.
- **Vendor–Distributor Focus** — Purpose-built to bring structure and trust to recurring business meetings.

## 🛠️ Usage

Once set up, JARVIS can be used to:
1. Schedule a new vendor–distributor meeting.
2. Auto-generate an agenda based on meeting context.
3. Send reminders to all invitees ahead of time.
4. Capture and distribute follow-up notes/action items after the meeting.
